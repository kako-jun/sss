# sss - Smart Slide Show

_[Read this in English](README.en.md)_

10万枚以上の写真を公平に表示するスライドショーアプリケーション

## 特徴

- **完全平等ランダム表示**: 全画像を1巡するまで重複なし
- **高速差分スキャン**: 前回から更新日時（mtime）が変わったファイルだけを検出。起動時は前回の状態を即座に復元して表示を始め、スキャンはバックグラウンドで実行
- **動画対応**: 静止画（JPEG/PNG/GIF/BMP/WebP/TIFF）に加え、動画（MP4/WebM/OGV/M4V）も同じ順番の中で再生
- **4K対応**: 高解像度ディスプレイに最適化、自動リサイズ＆キャッシュ
- **Tauriプロトコル画像ロード**: クロスプラットフォーム対応の効率的な画像読み込み
- **5枚先読みキャッシュ**: スムーズな画像切り替え（弱いCPU対応、直列処理）
- **表示統計**: 表示回数と最新表示時刻を記録・表示
- **EXIF情報表示**: 撮影日時、GPS座標を表示
- **除外ルール**: 日付・ファイル・フォルダ単位で除外ルールを管理（設定画面の「除外ルール」タブ。旧 `.sssignore` は初回スキャン時にDBへ自動移行）
- **動画の音声・最大再生時間**: 動画の音声のオン/オフ（既定: オフ）と最大再生時間（無制限/30秒/1分/2分/5分。既定: 無制限）を設定画面で変更可能
- **スクリーンセーバー抑制**: 常にディスプレイをオンに保つ
- **クロスプラットフォーム**: Windows/Linux/macOS対応
- **日本語/英語対応**: OSのロケールを自動判定、設定画面（オプション）で手動切替も可能

## インストール

### ビルド済みバイナリ（Releases）

[Releases](https://github.com/kako-jun/sss/releases) から、お使いのOS向けのファイルをダウンロードします（最新は v1.1.0）。

| OS      | ファイル                                                        |
| ------- | --------------------------------------------------------------- |
| Windows | `sss_*_x64-setup.exe`（NSISインストーラー）                     |
| macOS   | `sss_*_universal.dmg`（Apple Silicon / Intel 共通）             |
| Linux   | `sss_*_amd64.AppImage` / `sss_*_amd64.deb` / `sss-*.x86_64.rpm` |

#### 未署名アプリの警告について

配布物にコード署名はしていないため、初回起動時にOSが警告を出します。

- **Windows（SmartScreen）**: 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を選びます
- **macOS（Gatekeeper）**: 「開発元を確認できません」と表示されたら、Finder でアプリを右クリック（Control+クリック）→「開く」を選びます。または「システム設定 → プライバシーとセキュリティ」に出る「このまま開く」を押します。それでも開けない場合は、ターミナルで `xattr -dr com.apple.quarantine /Applications/sss.app` を実行します
- **Linux**: 警告はありません。AppImage は `chmod +x sss_*.AppImage` で実行権限を付けてから起動します

### ソースからビルドする

#### 必要なもの

- Node.js（v20.19 以上、または v22.12 以上。Vite 7 の要件。CI は Node 22）
- Rust（v1.90 以上、rustup 経由。tauri 2.12 の MSRV）
- Linux のみ、Tauri のビルド依存パッケージ（CI と同じ。Ubuntu 22.04 の例）:

```bash
sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev patchelf
```

#### セットアップ

```bash
# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run tauri:dev

# ビルド
npm run tauri:build
```

#### 開発用コマンド

```bash
npm test          # フロントエンドのテスト（vitest）
npm run lint      # ESLint
npm run e2e       # 実ブラウザ e2e（ローカル専用。詳細は e2e/README.md）
cd src-tauri && cargo test   # バックエンドのテスト
```

## 使い方

### 初回起動

1. 写真フォルダが一度も設定されていない場合、ようこそ画面が表示されます（初回は全画面で起動します）
2. 「フォルダを選択」ボタンで設定画面（「フォルダ」タブ）が開きます。「選択」ボタンでダイアログを開き、写真・動画が入ったフォルダを選びます（選ぶとすぐにスキャンが始まります）
3. スキャンが完了すると、追加・削除されたファイル数などが表示されます
4. 設定画面を閉じる（右上の×ボタンまたは ESC）と、スライドショーが再生されます

2回目以降の起動では、前回のフォルダを自動で復元してすぐに表示を始め、変更分のスキャンはバックグラウンドで行います。

### 基本操作

#### マウス操作

- **マウス移動**: オーバーレイUI（画面下中央のバー）と右上のボタン列を表示します。3秒間マウスを動かさないとフェードアウトし、マウスカーソルも隠れます
- **オーバーレイのバーにマウスを乗せる**: 乗せている間はスライドショーが自動的に一時停止し、離れると再開します（マウスを動かしただけでは止まりません）。設定画面を開いている間も一時停止します
- **写真をクリック**: 一時停止/再開を切り替える（素早い連打・ダブルクリックは1回にまとめる。オーバーレイのボタンや設定画面の操作とは干渉しません）
- **写真の上でホイール／トラックパッドの横スワイプ**: 前/次の写真へ（慣性スクロールで何枚も飛ばないよう、1回の操作につき1枚）
- **オーバーレイのボタン**:
  - **前へ**: 前の写真・動画に戻る（履歴から。表示回数は増やしません）
  - **⏸/▶**: 一時停止/再開を切り替える
  - **次へ**: 次の写真・動画へ即座に進む
  - **ピック**（手のアイコン）: 表示中のファイルをピック先フォルダ（既定: `Pictures/sss-picked`）へコピーする
  - **「…」メニュー**: ファイルマネージャーで開く・ピックを見る・除外（撮影日付／フォルダ／ファイルの単位）
  - **GPS付きの写真の地図サムネイル**: クリックでGoogleマップを開く
- **取り消す**: 除外・ピックの直後の数秒だけ、控えめなトーストに「取り消す」が出る。押すと除外ルールを外して写真をプレイリストの未再生分へ戻す／ピックでコピーしたファイルを削除する（確認ダイアログなし）
- **右上のボタン列**（左から: ショートカット一覧・ウィンドウモード切替・設定・終了）: マウス操作中は表示され、オーバーレイ同様にidleでフェードアウトします
- **ウィンドウ状態の記憶**: 前回のウィンドウモード（全画面/ウィンドウ）・位置・サイズを終了時に保存し、次回起動時に復元する。保存先のディスプレイが外れていれば既定の位置に出ます

#### キーボードショートカット

- **ESC**: アプリを終了（設定画面・ショートカット一覧・「…」メニューを開いている間は、それを閉じるだけ）
- **左矢印キー**: 前の画像へ戻る
- **右矢印キー**: 次の画像へ進む
- **Space**: 一時停止/再開を切り替える（設定画面を開いている間は無効）
- **F / F11**: フルスクリーンとウィンドウモードを切り替える（macOSでは`F11`がOS標準のミッションコントロールに割り当てられていることが多く、アプリまで届かない場合があります。macOSでは`F`キーか`fn + F11`を使ってください）
- **?**: キーボードショートカット一覧を表示（写真上のクリック/ホイール操作も載っています）

### 除外ルール

設定画面の「除外ルール」タブで、日付・ファイル・フォルダ単位の除外ルールを一覧管理できます（オーバーレイUIの「…」メニューからも、表示中の画像をその場で日付/ファイル/フォルダ単位に除外できます）。ルールはアプリ内のデータベースに保存されます。

旧バージョンで使っていたホームディレクトリ（Windows: `%USERPROFILE%`、Unix: `$HOME`）の `.sssignore`（gitignore形式）は、初回スキャン時に一度だけデータベースへ自動移行され、`.sssignore.bak` にリネームされます（以降は読み込まれません）。

### 設定画面

右上の歯車ボタン（またはようこそ画面のボタン）で開きます。タブは次の7つです。

| タブ       | 内容                                                                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| フォルダ   | 写真フォルダの選択（選んだフォルダをすぐスキャン）と、選択済みフォルダの再スキャン（結果: ファイル数・新規・削除・処理時間・読み取りエラー） |
| オプション | 表示間隔（5〜60秒）・EXIF回転に従う・動画の音声（既定: オフ）と最大再生時間・ピック先フォルダ・言語                                          |
| 除外ルール | 登録済みルールの一覧・解除・手動追加                                                                                                         |
| ピック     | ピックした写真・動画の一覧と削除                                                                                                             |
| 履歴       | 最近表示した写真（最新100件）と、そこからの除外                                                                                              |
| 統計グラフ | 表示回数の分布（棒グラフ・表）と「表示回数をリセット」                                                                                       |
| 情報       | バージョン・GitHubリンク・「設定を初期化」（全データを削除してアプリを再起動。ピック済みファイルは残ります）                                 |

動画は表示間隔ではなく、最後まで再生してから（または「動画の最大再生時間」に達したら）次へ進みます。言語は「自動（OSのロケール）/ 日本語 / English」から選べます。

## オーバーレイUI情報

マウス移動時に、画面下中央の角丸バーに表示される情報（情報が無い項目は表示しない）：

- 🗺️ 位置情報（GPSがある写真だけ、小さな地図サムネイルを表示。クリックでGoogleマップを開く）
- 📅 撮影日（EXIFにある画像だけ）
- 📁 ファイル名・プレイリスト位置（例: 1,234 / 100,000）
- ファイルサイズ・表示回数・最終表示日時はファイル名のツールチップ（ホバー時）で確認
- 写真の下端には、次の写真へ切り替わるまでの進捗を示す極細のラインが表示されます

表示回数・最終表示時刻の一覧や統計は、設定画面の「履歴」「統計グラフ」タブで確認できます。

## パフォーマンス

- 初回スキャン（10万枚）: < 30秒
- 差分スキャン（変更100枚）: < 3秒
- 起動からスライドショー開始: < 5秒（差分スキャン時）
- 画像切り替え: < 100ms
- メモリ使用量: < 500MB

上記は目標値です。内部ベンチマーク（`src-tauri/tests/scan_reflection_throughput.rs`・`db_reflection_throughput.rs`、いずれも`#[ignore]`）による実測値は `docs/architecture.md`「6. 主要な設計判断 (b) 差分スキャン」を参照してください。

## サイネージ用途での運用

常時稼働させる場合は、OS側で自動起動・終了を管理することを推奨します：

### Windows: タスクスケジューラー

- 毎日8:00に起動、22:00に終了を設定
- PCの再起動後も自動で動作

### Linux: cron / systemd timer

- cronで起動・終了を設定

### macOS: launchd

- plistファイルで起動・終了を設定

詳細は `CLAUDE.md` を参照してください。

## 関連ツール

### photo-returns との組み合わせ

[photo-returns](https://github.com/kako-jun/photo-returns) は、EXIFメタデータに基づいて写真・動画を `YYYY/YYYYMM/YYYYMMDD` 形式のフォルダ構造へ整理するツールです。

**推奨フロー:**

1. **photo-returns** でカメラやスマートフォンから取り込んだ写真を年月日フォルダへ整理
2. **sss** で整理済みフォルダをスライドショーとして鑑賞

どの写真にも公平に出番が来る sss と、写真を見つけやすく整理する photo-returns は、組み合わせて使うことができます。
