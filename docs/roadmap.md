# ロードマップ

## 実装済み（以前はここに載せていたもの）

- **起動時の自動差分スキャン**: アプリ起動時に前回のフォルダを自動で復元して即座に表示を始め、差分スキャンはバックグラウンドで実行します（#62）。ボタン操作は不要です
- **EXIF回転の設定**: 設定画面のオプションタブで、EXIF向き情報の自動反映をオン・オフできます（既定: オン）
- **動画の長さへの対応**: 動画は表示間隔ではなく再生終了まで表示し、設定画面で最大再生時間（無制限 / 30秒 / 1分 / 2分 / 5分）と音声のオン・オフも選べます（#68）
- **日本語/英語の多言語対応**（#80）、**除外・ピックの取り消し**と**ウィンドウ状態の記憶**（#78）

## 近い将来に届けたいこと

### 旧フォーマット動画への対応（ffmpeg 同梱、#45）

現在再生できる動画は、WebView がそのまま再生できる MP4 / WebM / OGV / M4V です。AVI・MKV・FLV・WMV などは、ffmpeg を同梱して変換再生することで対応する予定です。

### 動画のメタ情報表示

動画ファイルの長さ・解像度・コーデックなどのメタ情報を取得し、オーバーレイに表示します。現在、動画のオーバーレイにはファイル名とプレイリスト位置だけが表示されます。

## もう少し先の展開

### タブレット・モバイル対応

デジタルフォトフレームとして部屋に置いたタブレットで SSS を動かしたい、というユースケースに応えます。スワイプで前後移動、タップでオーバーレイ表示など、タッチ操作に最適化した体験を届けます。縦画面・横画面のどちらでも自然に使えるよう、画面サイズに柔軟に対応します。

### フォルダ変更時の表示回数の自動リセット（任意設定）

フォルダを選び直すたびに表示回数を 0 に戻すかどうかを選べる設定です。現状は、フォルダを切り替えても表示回数は保持されます（統計タブの「表示回数をリセット」で手動リセットは可能）。
