# 主要機能

## 完全平等ランダム表示

すべての写真・動画を一巡するまで重複なしで表示します。一般的な「ランダム」は同じ写真が繰り返されがちですが、SSS は全員に一度ずつ出番が来るまで次のラウンドを始めません。10万枚のコレクションでも、すべての写真が同じ頻度で表示されることを保証します。

シャッフル順・現在位置・閲覧履歴はSQLiteに保存され、アプリを再起動しても巡の途中から再開します（#62）。10万枚×表示間隔だと1巡に何日もかかることがあり、毎日アプリを再起動する運用では起動のたびに最初から再シャッフルしていると1巡が終わらず「完全平等」が成立しないため、この永続化は本機能の前提です。起動直後は保存済みの状態をスキャン完了を待たずに復元して即座に表示を始め、スキャンはバックグラウンドで実行して差分（増えた/消えた写真）だけを後から反映します。

保存できるのは常に1フォルダぶんの「シャッフル順・現在位置」だけです。フォルダA→B→Aと切り替えた場合、Aの巡の途中経過はBに切り替えた時点で失われ、Aに戻ると新しい巡として最初からシャッフルし直します（複数フォルダの進捗を同時に保持する設計ではありません）。一方、各写真の「何回表示されたか」（表示統計）とファイル自体の登録情報は、フォルダを切り替えても消えません（後述）。

## 差分スキャン

写真フォルダを登録すると、SSS はファイルを自動検出します。初回だけフルスキャンを行い、2回目以降は前回から変わったファイルだけを処理します。変更の判定は更新日時（mtime）の比較だけなので、10万枚規模でも起動を重くしないことを目標にしています（目標値であり、フルアプリでの通し計測はしていません。バックエンド単体のベンチ結果は `docs/architecture.md` §6(b) を参照）。

差分の比較対象は今スキャンしているフォルダの中だけです。複数の写真フォルダを切り替えて使っても、他のフォルダの登録情報や表示統計が誤って消えることはありません。フォルダの読み取り中にエラー（権限やネットワーク切断など）が起きても、そのファイルを「削除された」と誤判定して統計を消すことはありません。それだけでなく、スライドショーの巡から外れることもありません（シャッフル順・現在の再生位置・履歴はそのまま保たれます）。次回スキャンで読めるようになれば、何ごともなかったかのように元の状態のまま扱われます（実際に削除されたと確認できれば、通常どおり巡から取り除かれ統計も消えます）。

なお、読めない状態が続いている間にその写真の順番が回ってきても、読み込みに失敗した写真は自動で次の写真へ進みます（連続で失敗し続けた場合だけ通知が出ます、#65）。

## 動画の再生

動画（MP4/WebM/OGV/M4V）は写真と同じ順番の中に混ざって流れ、最後まで再生されてから次へ進みます。音声は既定でオフ（無音）で、設定画面の「オプション」タブ →「動画」で音声を再生するように切り替えられます。長い動画は、同じ場所の「動画の最大再生時間」（無制限 / 30秒 / 1分 / 2分 / 5分）で途中で打ち切って次へ進めることもできます（#68）。

## ファイル除外設定

スライドショーから除外したいフォルダやファイルをオーバーレイの「…」メニューから直接指定できます。「プライベートフォルダは見せたくない」「スクリーンショットは邪魔」「あの時期の写真は今は見たくない」といった細かい気持ちに応えます。除外ルールはアプリ内の SQLite データベースに保存されます。

撮影日付・ファイル単体・フォルダの3種類の除外方法から選べます。除外した直後の数秒は、控えめなトーストの「取り消す」でやり直せます（確認ダイアログを増やさず、押し間違えてもすぐ戻せます。除外ルールを外し、写真を未再生の区間へ戻します。除外は削除ではないので写真も表示履歴も無傷です。フォルダ/撮影日除外は再スキャンで外れる仕組みなので、除外後に再スキャンが走ってから取り消した場合、外れた写真の復帰は次の再スキャンで行われます、#78）。設定画面の「除外ルール」タブで登録済みルールの一覧表示・解除・手動追加もできます。

## お気に入り（ピック）

スライドショー中に「これをピックしたい」と思ったとき、オーバーレイのピックボタン（手のアイコン）からワンクリックで写真・動画をコピーできます。コピー先はピクチャフォルダ内の `sss-picked` フォルダです。設定画面からコピー先のフォルダパスを変更することもできます。ピック直後の数秒は「取り消す」で、そのコピーだけをすぐに消せます（#78）。「…」メニューの「ピックを見る」からピックタブを直接開いて、ピック済み写真の一覧確認・削除もできます。

## 写真上のマウス操作とウィンドウ状態の記憶

写真の上をクリックすると一時停止/再開、ホイール（トラックパッドは横スワイプ）で前/次へ移れます。ダブルクリックや慣性スクロールで意図せず何枚も進まないよう、連続した操作は1回にまとめます。ウィンドウの状態（全画面/ウィンドウモード・位置・サイズ）は終了時に保存され、次回起動時に復元されます（保存先のディスプレイが外れていれば既定位置。#78）。

## 地図連携

GPS情報がある写真を表示しているとき、オーバーレイのバー左端に、OpenStreetMap タイルの小さな地図サムネイルを表示します。クリックで Google Maps を開けます。「どこで撮ったんだっけ」を確認できます。

## 統計グラフ

設定画面の統計タブで、表示回数の分布（表示回数ごとのファイル数）を棒グラフ（ヒストグラム）と表で確認できます。完全平等ランダムが正しく動いていれば、写真間の表示回数のばらつきは極めて小さいはずです。「本当に公平か？」という疑問に、数値と視覚で答えます。グラフは今スキャンしているフォルダの写真だけを対象にします（過去に別フォルダをスキャンした際の表示回数は含まれません）。「表示済み/総数」の件数はさらに絞り込み、今のスライドショーに実際に含まれている写真（除外ルール適用後）だけを数えるため、除外設定を後から付けた写真の表示回数が紛れて総数を超えて見える、といったことは起きません。

## 表示統計の記録

写真ごとに「何回表示されたか」「最後にいつ表示されたか」を記録します。「この写真、何度見たんだろう」という好奇心に答えるとともに、完全平等ランダムが正しく働いているかを数値で確認できます。フォルダを切り替えても記録自体は消えず、同じフォルダへ戻れば続きから確認できます。

## スクリーンセーバー・スリープ抑制

アプリが起動している間、ディスプレイのスリープとスクリーンセーバーを自動的に抑制します。長時間の写真鑑賞や店舗サイネージで、気づいたら画面が消えていた、という状況を防ぎます。なお、ノートPCのフタを閉じた際のスリープは抑制しません（電力節約のため）。

## 多言語対応（日本語/English、#80）

UIの表示言語は起動時にOSのロケールを自動判定し、日本語（`ja`）以外の環境では英語で表示します。設定画面のオプションタブ（「言語」）から「自動／日本語／English」を手動で選ぶこともでき、切替は即座に画面へ反映されます。ウィンドウタイトルやフォルダ選択ダイアログの見出しも選んだ言語に追従します。日付表示は原則、言語によらず `YYYY-MM-DD` 形式で統一しています（オーバーレイの撮影日だけは言語に合わせた表記で、日本語は「2023年8月15日 12:34」、英語は "Aug 15, 2023, 12:34 PM" です）。
