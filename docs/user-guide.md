# 使い方ガイド

## 初回起動

1. アプリを起動すると設定画面が表示されます
2. 「フォルダ選択」ボタンで写真・動画が入ったフォルダを選びます
3. 「フォルダをスキャン」ボタンでスキャンを開始します
4. スキャン完了後、自動的にスライドショーが始まります

## 画面構成

### スライドショー画面

起動後、写真・動画がフルスクリーンで表示されます。背景は黒、写真はアスペクト比を保ったまま中央に配置されます。

オーバーレイUIはデフォルト非表示です。マウスを動かすと画面下部にフェードインし、3秒間マウスが動かないとフェードアウトします。設定ボタン（⚙️）とウィンドウモード切り替えボタンは右上に常時表示されています。

### オーバーレイUI

画面下部にフェードイン/アウトする半透明のバーです。上行（情報）と下行（操作）の2行構成です。

オーバーレイにマウスを乗せている間はフェードアウトせず、スライドショーも自動的に一時停止します。離れると3秒タイマーが再開し、スライドショーも再開します。

**上行（情報）**

| セル       | 内容                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 地図       | GPS情報がある場合は OpenStreetMap タイル表示。ない場合はグレーアウト |
| 撮影日時   | EXIFから取得（デジタル時計風の大きめ表示）                           |
| ファイル名 | ファイル名とファイルサイズ                                           |
| 位置/回数  | プレイリスト位置 / 総数、表示回数                                    |

**下行（操作）**

| ボタン | 動作                                                |
| ------ | --------------------------------------------------- |
| …      | サブメニューを開く（下記参照）                      |
| ピック | ファイルを `~/Pictures/sss-picked` フォルダにコピー |
| 前へ   | 履歴をさかのぼって前の写真に戻る                    |
| ⏸/▶    | スライドショーの一時停止/再開をトグル               |
| 次へ   | 即座に次の写真へ進む                                |

**… サブメニュー**

| 項目                       | 動作                                                   |
| -------------------------- | ------------------------------------------------------ |
| ファイルマネージャーで開く | OSのファイルマネージャーで該当ファイルを選択状態で開く |
| ピックを見る               | 設定画面のピックタブを直接開く                         |
| 除外                       | サブメニューで3種類から選択（下記参照）                |

**除外サブメニュー**

| 項目               | 動作                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| 撮影日付で除外     | EXIF撮影日付（`DateTimeOriginal`優先）で除外する専用ルールを追加       |
| ディレクトリを除外 | 親フォルダ配下をサブフォルダも含めて再帰的に除外                       |
| ファイルを除外     | そのファイルだけを除外（ファイル名にglobのメタ文字があっても自己一致） |

除外ルールはデータベース（`ignore_rules`テーブル）に追記されます。反映は「ファイルを除外」のみ即座、「撮影日付で除外」「ディレクトリを除外」は次回スキャンから効きます。

### 設定画面

| 項目             | 説明                                                                                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| フォルダ選択     | スライドショー対象のフォルダをダイアログで選択                                                                                                             |
| スキャン実行     | 選択したフォルダをスキャンしてファイルを検出                                                                                                               |
| スキャン結果     | 追加・更新・削除されたファイル数と総ファイル数を表示。読み取れなかったファイル/フォルダがあれば件数と代表例も表示し、それらは削除扱いにせず保持する（#63） |
| 表示間隔         | スライドショーの切り替え間隔（5〜60秒）                                                                                                                    |
| ピック先フォルダ | フッタのピックボタンでコピーされる先のフォルダパス（デフォルト: `~/Pictures/sss-picked`）                                                                  |
| 除外ルール       | 登録済みの除外ルール一覧表示・解除・手動追加（撮影日ルールは「撮影日」バッジ表示、手動追加は通常globのみ）                                                 |
| ピック           | ピック済み写真のサムネイルグリッド表示・削除                                                                                                               |
| 履歴             | 最近表示した写真のサムネイルグリッド（最新100件）・除外操作                                                                                                |
| 統計グラフ       | 全写真の表示回数を棒グラフで表示・表示回数リセット                                                                                                         |
| 情報             | アプリ情報・GitHubリンク・「設定を初期化」（全データ初期化、下記参照）                                                                                     |

## 全データ初期化

設定画面の「情報」タブ→「設定を初期化」ボタンで、フォルダ選択・除外ルール・表示間隔・ピック先・表示履歴（回数/最終表示日時）などすべての設定とデータを工場出荷状態に戻せます。確認ダイアログで同意すると即座に実行され、成功すると**アプリ自体が自動的に再起動**し、初回起動時と同じ画面（フォルダ未選択のようこそ画面）で立ち上がります（ウィンドウが一瞬閉じて再度開きます）。実行中にスキャンが進行中だった場合は「スキャン実行中です。完了までお待ちください。」と表示され初期化は行われません。失敗した場合もエラーメッセージが画面に表示され、アプリは再起動せず、データは変更されません。

## 除外設定

除外ルールはアプリ内の SQLite データベースに保存されます。オーバーレイの「…」メニューから直接パターンを追加できます。設定画面の「除外ルール」タブで登録済みルールの一覧表示・解除・手動追加ができます。

末尾が `/` の除外パターン（`@eaDir/`・`.thumbnails/` など、初期設定済み）は、スキャン対象フォルダのどこかにその名前のディレクトリがあれば、その配下のファイルをすべて除外します。ディレクトリ除外もサブフォルダを含めて再帰的に除外されます。手動でパターンを追加する場合、glob として不正な文字列（閉じていない `{` など）はエラーになります。

撮影日での除外は、一度でも表示してEXIF撮影日をデータベースに記録済みの写真であれば正確に除外されます。撮影日ルールが1件以上設定されている間は、スキャン時にもまだ記録の無い（または前回スキャン後にファイルが変わった）写真のEXIFを読み直すため、一度も表示していない写真でも基本的には次のスキャンで正しく除外されます。それでも読み取れなかった場合（EXIF自体が無い等）は、ファイルパスに `YYYY-MM-DD` や `YYYYMMDD` の日付が含まれていれば代わりにそれで判定します（撮影日ルールが無ければEXIFは一切読みません。10万枚規模でのスキャン速度を守るためです）。

**撮影日ルールを新しく追加した直後の初回スキャンは、まだ記録の無い写真全件のEXIFを読み直すため一時的に重くなります**（極小フィクスチャでの実測ではローカルSSDで約68,000〜77,000件/秒だが、実際の写真は数MB級でこの上限値より大幅に遅くなり、NASなど遅延の大きいストレージ経由ではさらに遅くなり得ます）。2回目以降のスキャンでは、ファイルの更新日時（mtime）が前回記録と一致する写真は読み直さないため、通常は初回のみ体感できる重さです。

除外ルールで対象外になった写真は「削除」とは扱われません。表示履歴（表示回数・最終表示日時）は保持されたまま、スライドショーの対象からのみ外れます。ルールを解除すれば次回スキャンで元通り対象に戻ります。

以前のバージョンで `~/.sssignore` を使用していた場合、**初回スキャン時**に一度だけ自動的にデータベースへ移行されます（元ファイルは `~/.sssignore.bak` にリネームされます。移行後に `~/.sssignore` を作り直しても再移行はされません）。

## サイネージ用途での運用

店舗や施設での常時表示など、自動起動・終了が必要な場合は OSの機能を利用します。アプリ内部にタイマー機能は持っていません。

- **Windows**: タスクスケジューラーで起動・終了を設定
- **Linux**: cron または systemd timer で管理
- **macOS**: launchd の plistファイルで設定
