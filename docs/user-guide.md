# 使い方ガイド

## 初回起動

1. アプリを起動すると、フォルダを一度も設定していない場合は「ようこそ SSS へ」画面が表示されます（初回は全画面で起動します）
2. 「フォルダを選択」ボタンを押すと設定画面（「フォルダ」タブ）が開きます。「選択」ボタンでダイアログを開き、写真・動画が入ったフォルダを選びます。選ぶとすぐにスキャンが始まります（ダイアログをキャンセルした場合は何も変わりません）
3. スキャンが完了すると、ファイル数・新規・削除・処理時間などが表示されます
4. 設定画面を閉じる（右上の×ボタンまたは ESC）と、スライドショーが再生されます（設定画面を開いている間は一時停止しています）

2回目以降の起動では、前回のフォルダを自動で復元してすぐに表示を始め、変更分のスキャンはバックグラウンドで行います。

### 案内画面（#65）

「ようこそ SSS へ」画面が出るのは、フォルダを一度も設定していない本当の初回起動時
だけです。フォルダを設定済みの場合、状況に応じて別の案内になります:

- 除外ルール等で表示できる写真が0件になった場合は「表示できる写真がありません」
- フォルダに接続できない（NAS/USB切断など）場合は、直前まで見ていた写真を維持した
  まま「フォルダに接続できません。再接続をお待ちください…」という控えめな通知
- 1枚の読込失敗では鑑賞が止まらず、自動で次の写真へ進みます（連続で失敗し続けた
  場合だけ通知が出ます）
- 起動時に前回のフォルダへ接続できなかった場合は、その理由が画面に表示されます

## 画面構成

### スライドショー画面

起動後、写真・動画がフルスクリーンで表示されます。背景は黒、写真はアスペクト比を保ったまま中央に配置されます。

写真の上では、**クリックで一時停止/再開**、**ホイール（トラックパッドなら横スワイプ）で前/次**の写真へ移れます（#78）。オーバーレイのボタンや設定画面・ショートカット一覧を開いている間の操作とは干渉しません。素早い連打（ダブルクリック）は1回の操作として扱い、慣性スクロールでも1回の操作につき1枚しか進みません。

ウィンドウの状態（全画面/ウィンドウモード・位置・サイズ）は終了時に保存され、次回起動時にそのまま復元されます。前回使っていたディスプレイが外れている場合は、OS既定の位置に表示されます（#78）。

オーバーレイUIはデフォルト非表示です。マウスを動かすと画面下部にフェードインし、3秒間マウスが動かないとフェードアウトします。右上の終了・ショートカット一覧・ウィンドウモード切替・設定ボタンも同じタイミングでフェードイン/アウトします（マウスカーソル自体も同時に隠れます、#66）。

### オーバーレイUI（#66視覚刷新）

画面下中央に浮かぶ、角丸のコンパクトなガラス調バー1本です（画面幅いっぱいの2段グリッドだった旧デザインから刷新）。左（情報）・中央（主要操作）・右（副次操作）の3クラスタ構成で、フェードイン/アウトは変わらずidleに連動します。

オーバーレイにマウスを乗せている間はフェードアウトせず、スライドショーも自動的に一時停止します。離れると3秒タイマーが再開し、スライドショーも再開します。

**左: 情報**

GPS情報がある写真だけ、小さな地図サムネイルが先頭に表示されます（無い場合は何も表示しません）。続けて「ファイル名 · 撮影日 · プレイリスト位置/総数」を1行で表示します（撮影日はEXIFにある場合だけ表示）。ファイルサイズ・表示回数・最終表示日時は本文には出さず、ファイル名にマウスを乗せるとツールチップでまとめて確認できます。

**中央: 主要操作**

| ボタン | 動作                                  |
| ------ | ------------------------------------- |
| 前へ   | 履歴をさかのぼって前の写真に戻る      |
| ⏸/▶    | スライドショーの一時停止/再開をトグル |
| 次へ   | 即座に次の写真へ進む                  |

**右: 副次操作**

| ボタン                 | 動作                                                |
| ---------------------- | --------------------------------------------------- |
| ピック（手のアイコン） | ファイルを `~/Pictures/sss-picked` フォルダにコピー |
| …                      | サブメニューを開く（下記参照）                      |

写真の下端には、次の写真へ切り替わるまでの進捗を示す極細のプログレスラインが常に画面幅いっぱいに表示されます（バー自体とは独立した要素）。

**除外サブメニュー**

| 項目           | 動作                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| 撮影日付で除外 | EXIF撮影日付（`DateTimeOriginal`優先）で除外する専用ルールを追加       |
| フォルダを除外 | 親フォルダ配下をサブフォルダも含めて再帰的に除外                       |
| ファイルを除外 | そのファイルだけを除外（ファイル名にglobのメタ文字があっても自己一致） |

**取り消し（#78）**: 除外・ピックの直後は数秒間だけ、画面下部の控えめなトーストに「取り消す」ボタンが出ます（確認ダイアログは出ません。何もしなければ約6秒で消えます）。除外の取り消しは、追加した除外ルールを外し、その場でプレイリストから外していた写真を**未再生の区間**へ戻します（すでに表示した分・履歴は変わりません）。写真そのものやその表示履歴は除外の時点でも削除されていないため、取り消しはルールとプレイリスト所属を元に戻すだけです。同じルールが元から登録済みだった場合は、そのルールは消しません。ピックの取り消しは、そのピックでコピーしたファイルだけを削除します。取り消せるのは直近の1件です。トーストにマウスを載せている間・キーボードでフォーカスしている間は消えず、離れると残り時間から再開します。除外で戻るものが無かった場合（元からあったルールで、その場で外れた写真も無い）は「戻すものはありませんでした」と表示されます。取り消しで戻るのは現在のフォルダの写真だけです。なお、フォルダ除外・撮影日除外は再スキャンで初めて写真が外れる仕組みのため、除外から取り消しまでの間に再スキャンが走った場合、ルールは外れますが再スキャンで外れた写真はその場では戻りません（設定画面から再スキャンすると戻ります。再スキャンは時間のかかる処理なので、取り消しでは自動実行しません）。

除外ルールはデータベース（`ignore_rules`テーブル）に追記されます。反映は「ファイルを除外」のみ即座、「撮影日付で除外」「ディレクトリを除外」は次回スキャンから効きます。除外に成功すると、種類によらずスライドショーは即座に次の写真へ進み、プレイリスト位置/総数の表示も更新されます（除外した写真をそのまま表示し続けない、#65）。

## 全データ初期化

設定画面の「情報」タブ→「すべてのデータを初期化」ボタンで、フォルダ選択・除外ルール・表示間隔・ピック先・表示履歴（回数/最終表示日時）などすべての設定とデータを工場出荷状態に戻せます。確認ダイアログには「完了後アプリが再起動します」と表示され、同意すると即座に実行されます。成功すると**アプリ自体が自動的に再起動**し、初回起動時と同じ画面（フォルダ未選択のようこそ画面）で立ち上がります（ウィンドウが一瞬閉じて再度開きます）。実行中にスキャンが進行中だった場合は「スキャン実行中です。完了までお待ちください。」と表示され初期化は行われません。失敗した場合もエラーメッセージが画面に表示され、アプリは再起動せず、データは変更されません。

**ピック済みの画像ファイル（ピック先フォルダ）は削除されません。** 初期化が消すのは、アプリ内部のデータベース（設定値・フォルダ選択・除外ルール・スキャン済みのファイル情報・プレイリスト・表示履歴・スキャン履歴）、読み込みキャッシュ（サムネイル・最適化画像）、メモリ上の状態です。ピック機能でコピーした写真の実体はそのままディスクに残り、ピック先の指定は既定（`Pictures/sss-picked`）に戻り、ピックタブにはそのフォルダのファイルが表示されます。以前のピック先をカスタムしていた場合、そのフォルダのファイルは削除されませんが、タブには表示されなくなります。ウィンドウの位置・サイズ・全画面状態の記憶は消えません。

| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 左矢印  | 前の写真へ戻る                                                                                                                                           |
| 右矢印  | 次の写真へ進む                                                                                                                                           |
| Space   | 一時停止 / 再開を切り替える                                                                                                                              |
| F / F11 | フルスクリーンとウィンドウモードを切り替える                                                                                                             |

キーボードのほか、写真の上では**クリック（一時停止/再開）**と**ホイール／横スワイプ（前/次）**も使えます（#78）。右上のキーボードアイコンボタン、およびようこそ画面の「? ショートカット一覧を表示」（クリックできます、#100）からもショートカット一覧を開けます（#66）。マウスを3秒間操作しないと、オーバーレイと右上の常設ボタン（終了・ショートカット・ウィンドウモード・設定）に加えてマウスカーソル自体も非表示になり、写真の鑑賞を妨げません。マウスを動かすとすぐに復帰します。

> **macOS の注意点**: macOS 標準のキーボードでは `F11` は OS 側のミッションコントロール（デスクトップ表示）に割り当てられていることが多く、アプリまでキーが届かないことがあります。macOS では `F` キー、またはノートPCキーボードでは `fn + F11` を使ってください（#66レビューnit）。

## 除外設定

除外ルールはアプリ内の SQLite データベースに保存されます。オーバーレイの「…」メニューの「除外」から、表示中の写真を撮影日付・フォルダ・ファイルの単位で除外できます。設定画面の「除外ルール」タブで登録済みルールの一覧表示・解除・手動追加（glob パターン。例: `**/thumbs/`）ができます。

末尾が `/` の除外パターン（`@eaDir/`・`.thumbnails/` など、初期設定済み）は、スキャン対象フォルダのどこかにその名前のディレクトリがあれば、その配下のファイルをすべて除外します。ディレクトリ除外もサブフォルダを含めて再帰的に除外されます。手動でパターンを追加する場合、glob として不正な文字列（閉じていない `{` など）はエラーになります。

撮影日での除外は、一度でも表示してEXIF撮影日をデータベースに記録済みの写真であれば正確に除外されます。撮影日ルールが1件以上設定されている間は、スキャン時にもまだ記録の無い（または前回スキャン後にファイルが変わった）写真のEXIFを読み直すため、一度も表示していない写真でも基本的には次のスキャンで正しく除外されます。それでも読み取れなかった場合（EXIF自体が無い等）は、ファイルパスに `YYYY-MM-DD` や `YYYYMMDD` の日付が含まれていれば代わりにそれで判定します（撮影日ルールが無ければEXIFは一切読みません。10万枚規模でのスキャン速度を守るためです）。

**撮影日ルールを新しく追加した直後の初回スキャンは、まだ記録の無い写真全件のEXIFを読み直すため一時的に重くなります**（極小フィクスチャでの実測ではローカルSSDで約68,000〜77,000件/秒だが、実際の写真は数MB級でこの上限値より大幅に遅くなり、NASなど遅延の大きいストレージ経由ではさらに遅くなり得ます）。2回目以降のスキャンでは、ファイルの更新日時（mtime）が前回記録と一致する写真は読み直さないため、通常は初回のみ体感できる重さです。

除外ルールで対象外になった写真は「削除」とは扱われません。表示履歴（表示回数・最終表示日時）は保持されたまま、スライドショーの対象からのみ外れます。ルールを解除すれば次回スキャンで元通り対象に戻ります。

以前のバージョンで `~/.sssignore` を使用していた場合、**初回スキャン時**に一度だけ自動的にデータベースへ移行されます（元ファイルは `~/.sssignore.bak` にリネームされます。移行後に `~/.sssignore` を作り直しても再移行はされません）。

## サイネージ用途での運用

店舗や施設での常時表示など、自動起動・終了が必要な場合は OSの機能を利用します。アプリ内部にタイマー機能は持っていません。

- **Windows**: タスクスケジューラーで起動・終了を設定
- **Linux**: cron または systemd timer で管理
- **macOS**: launchd の plistファイルで設定
